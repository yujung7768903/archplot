말로 설명하면 클라우드 공식 아이콘이 들어간 아키텍처 다이어그램을 그려 주는 Claude Code 스킬이다.
결과는 draw.io 에서 바로 열어 고칠 수 있는 `.drawio` 파일과 PNG 이미지로 나온다.

## 특징

- **공식 아이콘** — AWS·GCP·Azure·Kubernetes 등 17개 계열, 2,440개 아이콘
- **경계 박스** — 계정·리전·VPC·서브넷을 박스로 나눠 중첩한다
- **깔끔한 선** — 선이 도형과 글자를 피해 직각으로 연결된다
- **앱 설치 없이 렌더** — draw.io 데스크톱 앱 없이 PNG 를 만든다

## 설치

```bash
npx skills add yujung7768903/archplot
```

| 요구사항 | 비고 |
| --- | --- |
| Python 3 | 표준 라이브러리만 사용. 추가 런타임 의존성 없음 |
| `pip install diagrams` | 생성기가 읽는 벤더 아이콘 PNG 를 제공 |
| Chromium | `~/.cache/ms-playwright` 또는 `~/.cache/puppeteer` 에서 자동 탐지, 없으면 시스템의 `chromium` / `chromium-browser` / `google-chrome` |

## 사용법

Claude Code 에 그리고 싶은 구성을 말로 설명한다.

> 주문 API 가 SQS 에 주문을 넣고, Lambda 가 꺼내서 영수증을 S3 에 올리는 구성도 그려줘

## 선 연결 규칙

선은 아래 규칙을 지키며 도형을 연결한다.

| 규칙 | 이유 |
| --- | --- |
| 가로·세로로만 꺾는다 | 곡선·대각선은 흐름을 읽기 어렵다 |
| 곧게 갈 수 있으면 꺾지 않는다 | 꺾임은 정보가 아니다 |
| 도형을 가로질러 가지 않는다 | 선이 어디서 끝나는지 헷갈린다 |
| 글자 위를 지나지 않는다 | 이름이 가려진다 |
| 아이콘 모서리에서 선을 내지 않는다 | 선이 아이콘에서 떠 보인다 |
| 들어오는 선끼리 연결점을 겹치지 않는다 | 겹친 선은 하나로 보인다 |
| 깔끔한 길이 없으면 배치를 고친다 | 대각선으로 억지로 잇지 않는다 |

## 그림 규칙

AWS 레퍼런스 아키텍처 다이어그램에서 가져온 규칙이다.

- 리소스 하나에 노드 하나
- 아이콘이 있는 것만 노드가 된다 — 함수명·URL·필드명은 그리지 않는다
- 선 라벨은 1~3단어
- 사용자는 모든 경계 박스 바깥에 둔다
- 정상 흐름 하나만 그린다 — 오류·재시도·순번은 넣지 않는다
